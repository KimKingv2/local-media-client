# Flutter source bundle

The base Flutter project is stored as eight base64 text fragments in `parts/`. Tracked patch files under `patches/` add the WebDAV source, catalogue, native MediaKit playback integration, and later playback/scanner/UI, directory-timeout, media-library/search/player-control improvements, TMDB metadata scraping, scan/sidecar/artwork-cache reliability fixes, interrupted-scan recovery, local SQLite backup/restore, TinyMediaManager NFO metadata precedence, persistent WebDAV poster/backdrop caching, and selectable portable cache backups, plus a richer native player control surface.

From the repository root, reconstruct the exact buildable source with:

```bash
python3 source/reconstruct_source.py --output local-media-client
```

The helper validates the base archive and every compressed/split patch with SHA-256 checksums, extracts the Flutter project, and applies patches in the same order as the GitHub Actions workflow. Patch 0031 extends Kodi/TinyMediaManager NFO parsing and ensures local NFO values override TMDB fallback values. Patch 0032 caches recognized WebDAV poster/backdrop images in the app's durable artwork directory, with bounded reads, image-signature checks, and no media-body downloads. Patch 0033 adds `.lmcbackup` portable backups with separate export/import controls for provider scrape cache and cached artwork; credentials and API tokens are always excluded, while legacy raw SQLite imports remain supported. Patch 0035 upgrades the MediaKit player UI with central ±10-second controls, auto-hiding controls, double-tap seeking, playback speed selection, and a consolidated volume/audio/subtitle settings sheet. Patch 0036 adds selectable contain/crop/stretch video fitting and subtitle font-size/background controls, with unit coverage for the display preferences. Patch 0037 persists those display preferences in the local SQLite catalogue and adds keyboard/D-pad shortcuts for playback, ±10-second seeking, volume, mute, Android immersive mode, and Escape. Patch 0038 adds the explicit Flutter foundation import required by the platform-specific immersive-mode check. Patch 0039 scopes keyboard shortcuts to the focused player, prevents the global shortcuts from stealing input while the playback settings sheet is open, supports repeat for held seek/volume keys without repeating toggle commands, restores player focus after closing the sheet, and reapplies Android immersive mode when the app resumes. Patch 0040 handles video-surface pointer events with an explicit double-tap time window and movement threshold. A single tap is deferred until the window expires, while a left/right double tap seeks in that direction without also toggling the controls. Widget tests cover single taps, both seek directions, and drag rejection. The gesture tests intentionally calculate tap coordinates from the rendered PlayerGestureSurface size because the test root may impose tight screen dimensions. Patch 0041 removes temporary pointer-debug logging, calculates left/right double-tap test positions from the rendered surface size, and verifies that spatially separate taps remain independent single taps. Patch 0042 gives visible player controls a D-pad focus region with remembered focus, passes directional keys through to TV focus traversal while the control overlay is visible, retains arrow-key seeking and volume changes while controls are hidden, and prevents the auto-hide timer from dismissing controls while a remote is navigating. Shortcut tests cover directional pass-through and the retained playback commands. The output directory must be empty or not yet exist.

The Android and macOS GitHub Actions jobs call this helper directly. Avoid extracting only `parts/` and treating the result as the current app source: the later tracked patches are required.
