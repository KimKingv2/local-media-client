# Flutter source bundle

The base Flutter project is stored as eight base64 text fragments in `parts/`. Tracked patch files under `patches/` add the WebDAV source, catalogue, native MediaKit playback integration, and later playback/scanner/UI, directory-timeout, media-library/search/player-control improvements, TMDB metadata scraping, scan/sidecar/artwork-cache reliability fixes, interrupted-scan recovery, local SQLite backup/restore, TinyMediaManager NFO metadata precedence, persistent WebDAV poster/backdrop caching, and selectable portable cache backups, plus a richer native player control surface.

From the repository root, reconstruct the exact buildable source with:

```bash
python3 source/reconstruct_source.py --output local-media-client
```

The helper validates the base archive and every compressed/split patch with SHA-256 checksums, extracts the Flutter project, and applies patches in the same order as the GitHub Actions workflow. Patch 0031 extends Kodi/TinyMediaManager NFO parsing and ensures local NFO values override TMDB fallback values. Patch 0032 caches recognized WebDAV poster/backdrop images in the app's durable artwork directory, with bounded reads, image-signature checks, and no media-body downloads. Patch 0033 adds `.lmcbackup` portable backups with separate export/import controls for provider scrape cache and cached artwork; credentials and API tokens are always excluded, while legacy raw SQLite imports remain supported. Patch 0035 upgrades the MediaKit player UI with central ±10-second controls, auto-hiding controls, double-tap seeking, playback speed selection, and a consolidated volume/audio/subtitle settings sheet. Patch 0036 adds selectable contain/crop/stretch video fitting and subtitle font-size/background controls, with unit coverage for the display preferences. Patch 0037 persists those display preferences in the local SQLite catalogue and adds keyboard/D-pad shortcuts for playback, ±10-second seeking, volume, mute, Android immersive mode, and Escape. Patch 0038 adds the explicit Flutter foundation import required by the platform-specific immersive-mode check. Patch 0039 scopes keyboard shortcuts to the focused player, prevents the global shortcuts from stealing input while the playback settings sheet is open, supports repeat for held seek/volume keys without repeating toggle commands, restores player focus after closing the sheet, and reapplies Android immersive mode when the app resumes. Patch 0040 handles video-surface pointer events with an explicit double-tap time window and movement threshold. A single tap is deferred until the window expires, while a left/right double tap seeks in that direction without also toggling the controls. Widget tests cover single taps, both seek directions, and drag rejection. The gesture tests intentionally calculate tap coordinates from the rendered PlayerGestureSurface size because the test root may impose tight screen dimensions. Patch 0041 removes temporary pointer-debug logging, calculates left/right double-tap test positions from the rendered surface size, and verifies that spatially separate taps remain independent single taps. Patch 0042 gives visible player controls a D-pad focus region with remembered focus, passes directional keys through to TV focus traversal while the control overlay is visible, retains arrow-key seeking and volume changes while controls are hidden, and prevents the auto-hide timer from dismissing controls while a remote is navigating. Patch 0043 wraps the added auto-hide guard in an explicit block so the update does not add a new analyzer hint. Patch 0044 makes every player toolbar, center action and lower control an explicit D-pad focus target; seeking can be adjusted in 10-second steps with left/right while the seek control is focused. It makes control auto-hide restart on focus movement and checks modal state again when the timer fires, allows player shortcuts while a descendant control owns focus, and uses route-level back handling to exit Android immersive mode before popping the playback route. Shortcut tests cover directional pass-through and the retained playback commands. Patch 0045 protects focused TV controls from auto-hide, restores D-pad focus after dismissing the playback settings sheet, recognizes Android Go Back, and adds long-select 60-second skip actions. Patch 0046 serializes relative and absolute seeks, accumulates rapid remote key repeats against an optimistic target while the backend position stream catches up, keeps slider display aligned with that target, and recovers the seek queue after an individual seek failure. Five coordinator tests cover rapid repeats, queued acknowledgements, media boundaries, error recovery, and slider/remote seek ordering. Patch 0047 uses the optimistic seek target for watch-progress persistence while the backend position stream catches up, requests a throttled progress save after successful seeks, and persists a seek to zero so an old resume position cannot reappear. Coordinator tests cover background progress during a pending seek and clearing saved progress at the beginning of a video. Patch 0048 extracts a serialized watch-progress write queue that coalesces stale pending snapshots, exposes whether the drain succeeded, and lets system/UI back navigation wait for a forced progress flush before leaving the player (with a two-second safety timeout). Queue tests cover latest-snapshot coalescing, shared drain completion, failure reporting, and recovery. Patch 0049 routes system Back, keyboard/TV Back, the player toolbar Back button, and playback-open error Back through a single exit coordinator. Normal exits wait for the existing progress-flush path; immersive-mode Back exits immersive mode first. Concurrent exit requests share one in-flight progress flush. Added coordinator tests for normal exits, immersive exits, and concurrent requests. Patch 0050 adds a coalescing display-settings write queue and includes the latest video-fit and subtitle preferences in the same two-second exit-save barrier as watch progress. The disposed-page fallback still retries preference persistence if the barrier times out or a write fails. Queue tests cover rapid changes, latest-snapshot coalescing, concurrent completion, failure reporting, and recovery. Patch 0052 fixes duplicate `hidden`/`paused` notifications clearing resume intent after the coordinator's own pause; a regression test covers a late media open followed by duplicate background callbacks. Patch 0053 keeps the lifecycle cycle attached until native resume/foreground restoration completes, carries playback intent across an immediate re-background while a previous pause is still in flight, retries a pause canceled before it starts, and re-pauses if the app backgrounds during native play. Three regression tests cover those transition races. Patch 0054 extracts Flutter lifecycle observer registration and state dispatch into a dedicated binding used by the playback page. Widget tests send real `flutter/lifecycle` platform-channel messages to verify inactive/hidden/paused/resumed ordering, initial hidden-state reconciliation after a late media open, terminal detached handling, observer disposal, and an unknown initial state. Patch 0055 synchronizes the test binding to the hidden state before observer attachment, ensuring the resumed event is a real state transition rather than a duplicate notification. Patch 0051 adds a serialized playback lifecycle coordinator. It saves progress/settings on inactive/background transitions, pauses only after the app is actually hidden/paused, resumes only playback that the coordinator successfully paused, restores Android immersive UI and controls on foreground return, and reconciles media opens that finish while backgrounded. Lifecycle tests cover inactive-only transitions, prior paused state, pause/resume ordering, open completion races, rapid foreground return, pause failures, and detached shutdown. Patch 0045 prevents the player control overlay from auto-hiding while a D-pad control still owns focus, preserves the originating control focus after dismissing the playback settings sheet, recognizes Android's `Go Back` key alongside Escape, makes Play/Pause the first-entry focus target, and adds 60-second long-select actions to the ±10-second skip controls. Widget coverage verifies repeated held direction keys and long-select disambiguation. The automated key-event checks complement, but do not replace, final testing with a physical Android TV remote. The output directory must be empty or not yet exist.

Patch 0053 is the current lifecycle-coordinator head. The Android and macOS GitHub Actions jobs call this helper directly. Avoid extracting only `parts/` and treating the result as the current app source: the later tracked patches are required.
